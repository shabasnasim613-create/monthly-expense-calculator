# Pennywise — Monthly Expense Calculator

A responsive monthly income and expense tracker built with HTML, CSS and vanilla JavaScript.

## Features
- Monthly dashboard: income, expenses, balance and savings rate
- Add, edit and delete income/expense transactions
- Categories and notes
- Spending breakdown chart by category
- Monthly spending budget with progress and overspending warning
- Search and filter transactions
- Export monthly transactions to CSV
- Download and import a JSON backup
- INR formatting
- Responsive desktop and mobile layout
- Data is saved in the browser using localStorage; no account or server required

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `monthly-expense-calculator`.
2. Extract this ZIP file.
3. Upload `index.html`, `style.css`, `app.js`, and `README.md` to the repository root (not the ZIP itself).
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then save.
7. Wait a minute or two. GitHub will show your published website URL in the Pages section. It will look like:
   `https://YOUR-USERNAME.github.io/monthly-expense-calculator/`

## Privacy note
Transactions and budgets stay in that browser's local storage. They are not synced between devices and can be lost if browser site data is cleared. Use **Backup data** regularly. Do not enter bank passwords, card details, or other sensitive credentials.
